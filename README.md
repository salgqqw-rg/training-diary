# Дневник тренировок

Next.js + Supabase. Регистрация, личный кабинет, циклы по неделям, подходы с RIR и RPE, публичная лента и статистика прогрессии.

## Запуск

1. Создайте проект на supabase.com.
2. В SQL Editor выполните файл `supabase/schema.sql`.
3. В Authentication → Providers → Email для разработки отключите "Confirm email", чтобы вход работал сразу после регистрации.
4. Скопируйте `.env.example` в `.env.local` и вставьте URL проекта и anon key (Project Settings → API).
5. Установите зависимости и запустите:

   npm install
npm run dev

6. Откройте http://localhost:3000

## Деплой

Подключите репозиторий к Vercel и добавьте те же две переменные окружения.

## Безопасность

Права доступа заданы в базе через Row Level Security. Пользователь видит и меняет только свои циклы, публичные циклы видны всем. Проверка на сервере не даёт обойти эти правила из браузера.
